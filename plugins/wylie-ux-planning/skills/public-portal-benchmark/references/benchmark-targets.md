## 유형별 추천 대상 조합

### 접수 프로세스 개선 집중 분석 시
- 큐넷 (국내) + MySkillsFuture (해외) + GOV.UK (UX 기준)

### 디자인 시스템/KRDS 집중 분석 시
- 정부24 (KRDS 적용) + GOV.UK (GDS 기준) + Canada.ca

### 트래픽/성능 대응 집중 분석 시
- 큐넷 + 사이버국가고시센터 + JITEC IPA

### 접근성 집중 분석 시
- 정부24 + GOV.UK + Service NSW
