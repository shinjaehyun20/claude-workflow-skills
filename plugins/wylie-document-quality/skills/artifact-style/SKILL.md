# Artifact Style Gate

## 목적

새 스타일을 임의로 발명하지 않고, 승인된 기준 파일의 서식을 보존한다.

## 입력

- 편집 대상 또는 생성 요청
- 승인된 기준 파일 1개 이상
- 출력 경로

## 절차

1. **기준 잠금**: 발주처 송부본 → 공식 템플릿 → 승인된 최신본 순으로 기준을 고른다.
2. **스타일 추출**: 글꼴, 크기, 색, 여백, 표, 마스터/레이아웃, 열 너비를 도구로 읽어 표로 기록한다.
3. **사본 작업**: 원본이 아닌 별도 작업본에만 변경한다.
4. **스타일 적용**: 추출된 값만 사용한다. 기준에 없는 색·폰트·레이아웃은 사용자 승인 없이 추가하지 않는다.
5. **구조 검증**: 시트/슬라이드/섹션/ID 수와 순서가 의도치 않게 바뀌지 않았는지 비교한다.
6. **시각 검증**: 렌더 또는 미리보기로 잘림, 줄바꿈, 정렬, 대비, 이미지 깨짐을 확인한다.

## 도구 선택

- XLSX: `openpyxl` 또는 동등 도구
- PPTX: `python-pptx` 또는 동등 도구
- DOCX: `python-docx` 또는 동등 도구
- HWP/HWPX: 환경에서 지원되는 전용 도구. 지원되지 않으면 변환·검증 경로를 사용자에게 명시
- PDF: 렌더러와 텍스트/페이지 검사 도구

## 완료 조건

- 기준 파일과 해시 또는 버전이 기록됨
- 구조 차이가 승인 범위 안임
- 스타일 비교와 렌더 검증을 통과함
- 최종 파일명에 임시 접미사나 도구/에이전트명이 없음
