# Evidence-Backed Weekly Report

`weekly-report-evidence`는 업무 원본과 직전 계획을 대조해, 확인된 사실만으로 주간보고를 만드는 Claude Code 스킬입니다.

## 적합한 요청

```text
이번 주 업무 로그와 지난주 계획을 대조해서 주간보고를 작성해줘.
확인할 수 없는 내용은 완료로 쓰지 말고 별도 표시해줘.
```

```text
프로젝트 상태 보고를 만들어줘. 다음 주 계획은 실제 미완료·예정 항목만 넣어줘.
```

## 호출

```text
/weekly-report-evidence 2026-08-10부터 2026-08-14까지의 업무 기록으로 팀 주간보고를 작성해줘.
직전 보고서의 다음 주 계획을 대조하고, 결과는 reports/weekly.md에 저장해줘.
```

자연어로 주간보고 작성, 이전 계획 대조, 근거 기반 상태 보고를 요청해도 사용할 수 있습니다.

## 필요한 입력

- 보고 기간
- 업무 로그, 회의록, 결정 기록, 변경 이력 중 하나 이상의 source
- 대상 독자 또는 기존 보고서 양식

직전 보고서가 있으면 다음 주 계획과 실제 결과를 빠짐없이 대조합니다.

## 결과물

- source coverage ledger
- 이전 계획 대조표
- 이번 주 주요업무, 다음 주 계획, 성과, 이슈, 제안, 비고
- 확인 필요 사항과 저장 검증 결과

## 제한사항

- 원본이 없는 성과, 일정, 수신자, 완료 상태를 만들어 내지 않습니다.
- 자동 생성물이나 타인의 작업을 사용자 업무로 귀속하지 않습니다.
- 외부 게시, 전송, 승인에는 별도 명시 요청과 read-back이 필요합니다.
- 조직별 고유 경로, 고객명, 비공개 도구 설정은 패키지에 포함하지 않습니다.
