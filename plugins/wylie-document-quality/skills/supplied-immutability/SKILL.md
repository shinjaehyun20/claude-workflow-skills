# Supplied Source Immutability

## 원칙

제공받은 파일은 증거이자 기준이다. 직접 수정, 덮어쓰기, 이름 재사용을 금지한다.

## 시작 절차

1. 제공 원본의 전체 목록을 만든다.
2. 파일별 크기, 수정 시각, SHA-256을 기록한다.
3. 원본 영역과 작업 영역을 분리한다.
4. 작업본에는 `_working` 또는 새 버전명을 사용한다.
5. 추출 텍스트·렌더·중간 파일은 `work/` 또는 사용자가 지정한 임시 영역에 둔다.

## 허용

- 읽기 및 분석
- 사본 생성 후 편집
- 원본 경로와 해시를 근거로 참조

## 금지

- 원본 폴더에 결과 쓰기
- 원본과 동일한 파일명으로 결과 생성
- 파싱 결과를 원문으로 오인
- 메모·주석을 본문 사실로 승격
- 원본 해시가 바뀌었는데 작업 계속하기

## 종료 검증

- 시작/종료 원본 해시가 동일함
- 최종본이 원본 영역 밖에 있음
- 원본과 작업본의 관계가 manifest에 기록됨
