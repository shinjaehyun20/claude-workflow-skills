# Keep Working Loop

`keepworking-loop`은 작업을 무한 반복시키는 스킬이 아닙니다. 한 action unit을 **목표 고정 → 실행 → 검증 → 최소 수리 → 재검증 → 증거 기반 종료**로 처리하는 Claude Code 워크플로우입니다.

## 적합한 요청

```text
테스트가 깨졌어. 원인을 확인하고 고친 뒤 같은 테스트로 다시 검증해줘.
```

```text
이 기능을 구현하고 실제로 동작하는지 확인해줘. 완료 조건은 사용자가 파일을 업로드할 수 있는 것이다.
```

```text
계획은 충분해. 가장 작은 안전한 변경을 적용하고 결과를 증거와 함께 알려줘.
```

## 호출

Claude Code에서 다음처럼 호출합니다.

```text
/keepworking-loop <작업과 완료 조건>
```

또는 자연어로 실행·수정·검증까지 요청하면 Claude가 스킬을 선택할 수 있습니다.

## 기대하는 결과

- 목표와 제외 범위
- 실제 변경 또는 실행 내역
- 실행한 verifier와 결과
- 실패가 있었다면 최소 수리와 재검증 결과
- 남은 위험 또는 별도 승인 필요 항목

## 설치

이 저장소를 받은 뒤 필요한 스킬만 복사합니다.

```bash
mkdir -p .claude/skills
cp -R skills/keepworking-loop .claude/skills/
```

전역 설치는 사용자가 명시적으로 원하는 경우에만 선택하세요. 기존 동명 스킬이 있으면 먼저 diff를 확인합니다.

## 이름과 범위

`keepworking-loop`은 일반 계획·테스트·상태 보고 스킬과 다릅니다. 관찰 가능한 완료 조건, verifier, 실패 시 최소 repair와 재검증이 모두 필요한 경우에 사용합니다. 기존 환경에 `keepworking`이라는 동명 운영 스킬이 있을 수 있으므로, 이 공개 패키지는 다른 이름을 사용해 설치 충돌을 피합니다.

## 제한사항

- 삭제, 공개 게시, 결제, 권한 변경, 비밀정보 입력은 자동으로 수행하지 않습니다.
- 실제 runtime 검증이 불가능한 경우에는 완료를 추측하지 않고 제한을 보고합니다.
- 이 스킬은 프로젝트의 테스트·빌드·배포 체계를 대신하지 않습니다. 가능한 기존 verifier를 우선 사용합니다.
