# Wylie Project Folder Taxonomy

## Source Model

이 taxonomy는 일반적인 구축 프로젝트 문서 단계와 제공된 템플릿 구조에서 추출한 배포용 기준이다. 다른 조직에서 사용할 때는 `scripts/analyze_template.py <template-root>`로 자체 템플릿을 먼저 분석하고 routing rule을 조정한다.

- 파일명 권장: `프로젝트명_파일명_버전_날짜`
- 기준 루트는 사용자가 실행 시 전달한다. 개인·회사 절대경로를 가정하지 않는다.

## Cautions

- fallback 명칭은 `99.etc`로 통일한다.
- 조직별 템플릿과 충돌하면 조직 템플릿을 우선한다.
- 매칭되지 않은 파일은 임의 폴더로 옮기지 말고 수동 검토 목록에 남긴다.
