# Changelog

All notable changes follow Keep a Changelog principles.

## [0.1.0-alpha] - 2026-07-24

### Added

- Three skills-only Claude Code plugins.
- Eleven portable workflow skills selected from 298 top-level Claude source skills.
- Read-only source import, SHA-256 provenance manifest, and maintainer override layer.
- Cross-platform repository validator and GitHub Actions workflow.
- Installation, workflow, portability, security, and publication documentation.

### Excluded

- Hooks, MCP servers, OAuth, cookies, automatic external submission, and account-bound automation.
- Internal runtime ownership rules and incomplete delivery-lifecycle automation.
